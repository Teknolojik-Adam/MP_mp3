# MP MP3 — Linux

Basit MP3 oynatıcı. Linux sürümü Python Tkinter ve FFmpeg `ffplay` kullanır.

**Özellikler:** MP3 dosyası ekleme, listeden silme, oynat/duraklat/devam/durdur ve önceki/sonraki şarkı.

**Fedora kurulumu:**
```bash
sudo dnf install python3-tkinter ffmpeg
```

**Çalıştırma:**
```bash
python3 linux/mp3_player.py
```

Bu Linux sürümü Windows sürümünden ayrı ve daha basittir.
